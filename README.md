Vigla is a lightweight, Tableau-style dashboard for user acquisition in mobile games.

It loads campaign exports from ad networks and MMPs (AppLovin, Unity, Google, Meta, and others) through a column mapping, and each screen shows only what the loaded data supports.
It grew out of the internal pivot tables used to optimise ad network campaigns and is built for UA managers, account managers and team leads.

Status: in development, vanilla JS stage. A later version will be redone in TypeScript and the final version will answer plain-language questions about profitability for management.
