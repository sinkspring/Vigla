# Vigla

Vigla is a lightweight, Tableau-style dashboard for user acquisition in mobile games.

It loads campaign exports from ad networks and MMPs (AppLovin, Unity, Google, Meta, and others) through a column mapping, and each screen shows only what the loaded data supports.
It grew out of pivot tables my UA team used internally to optimise ad network campaigns and is built for UA managers, account managers and team leads.

Status: in development (v1 is Android only), vanilla JS stage. Types will be added once the domain functions settle (ADR-007), and the final version will let managers ask profitability questions in plain language.
